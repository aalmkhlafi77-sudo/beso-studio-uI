# Beso Studio UI — مصمم تأثيرات الواجهات

أداة ويب لتخصيص عناصر وتأثيرات واجهات المستخدم وتوليد مخرجات HTML/CSS قابلة لإعادة الاستخدام، باستخدام React وVite.

## التشغيل والتطوير

`npm run dev` للتطوير و`npm run build` للبناء و`npm test` للاختبارات.

## ملاحظات

هذا الوصف مستند إلى بنية المستودع ولا يؤكد اكتمال جميع الوظائف أو نجاح النشر. لا ترفع أسرار البيئة إلى GitHub.
